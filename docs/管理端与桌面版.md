# 管理端与桌面版（exe）

两件事：
1. **管理端** —— 看用户数、调用数、反馈数、全班薄弱点，并生成长期复盘
2. **桌面版 exe** —— 打包成一个双击即用的 Windows 程序（数据存 `%APPDATA%`）

---

## 一、管理端

> **只有管理员本人能看到入口。** 普通学生登录后，侧栏里**根本没有「管理端」**这一项，
> 直接访问 `#/admin` 也只会看到「无权访问」。数据接口同样会拒绝（403/401）。

### 谁能看到：三种模式

| 配置 | 谁是管理员 | 适用 |
|---|---|---|
| **`ZY_ADMIN_USER=用户名`** | 只有这个账号（正常登录后） | ✅ **公网部署推荐**：不用记口令，登录即管理员 |
| `ZY_ADMIN_TOKEN=口令` | 任何持有口令的人 | 不想建管理员账号时；或有多个管理员 |
| 两者都不配（单机模式） | 本机使用者 | 桌面版 / 自己电脑 |

两者都不配 + 公网多用户（`ZY_AUTH=1`）时，管理端**整体关闭** —— 避免任何注册学生看到全班数据。

```bat
:: Windows 本地/公网
set ZY_ADMIN_USER=老师甲
py -3 server.py
```

```bash
# Linux（.env 里加一行）
ZY_ADMIN_USER=老师甲
# 或者用口令：ZY_ADMIN_TOKEN=一串够长的随机字符
```

> 部署脚本 `deploy/oracle/install.sh` 会**自动生成一个随机 `ZY_ADMIN_TOKEN`** 写进 `.env`，
> 并在安装完成时提示怎么查看。

### 拿不到入口怎么进

1. 先确认后端配置生效：重启服务后看控制台/日志里的「管理端」行（桌面版启动横幅会打印）
2. 若用 `ZY_ADMIN_USER`：确认登录的**用户名完全一致**（大小写、空格都要一样）
3. 若用 `ZY_ADMIN_TOKEN`：直接访问 `#/admin`，在页面里粘贴口令
4. 口令连续错 8 次会被限流 5 分钟（防爆破）

### 能看到什么

| 区块 | 内容 |
|---|---|
| **KPI** | 学员数（近 7 天活跃）、近 30 天 AI 调用量（今日 / 平均耗时）、调用成功率、反馈条数与正负比、内容产出（问答/批改/诊断卷）、错题与积分总量 |
| **趋势** | 近 30 天每日「AI 调用次数」与「问答次数」柱状图 |
| **通道健康度** | 每条通道的调用数、失败数、失败率、平均耗时 —— 用来判断是不是某个通道在限流/欠费 |
| **全班共性薄弱点** | 掌握度低于 60 的考点，按「薄弱人数」排序 —— 教学上最该补的地方 |
| **学员明细** | 每人一行：问答数、AI 调用数（含失败）、反馈数、平均掌握度、薄弱点个数、最后活跃时间 |
| **长期总结** | 规则聚合的中文复盘；点「让 AI 写一份教学复盘」可让模型基于统计写 200–400 字建议 |

### 指标从哪来

| 指标 | 来源 |
|---|---|
| 学员数 / 活跃 | `data/db/<uid>/profile.json` + `history.jsonl` |
| 调用数 / 失败 / 耗时 / 通道 | `data/db/_metrics/llm_calls.jsonl`（每次模型调用追加一行） |
| 反馈数 | `data/db/_metrics/feedback.jsonl` + 各账号 `memory.json` |
| 内容产出 / 错题 / 积分 | 各账号 `profile.json`、`wrongbook.json`、`points.json` |

> **注意**：调用量与反馈量是**从本版本开始记录**的，之前的历史调用不会追溯。
> 明细默认保留 90 天（`ZY_METRICS_KEEP_DAYS` 可调），管理端有「清理 90 天前明细」按钮。

### 接口（自建看板可用）

```bash
GET  /api/admin/overview        # KPI + 通道
GET  /api/admin/daily?days=30   # 每日趋势
GET  /api/admin/users           # 学员明细 + 共性薄弱点
GET  /api/admin/longterm        # 规则版长期总结
POST /api/admin/ai-summary      # AI 复盘
POST /api/admin/prune           # 清理旧明细
```

鉴权：`?token=...` 或请求头 `X-Admin-Token: ...`。

## 二、桌面版 exe

### 构建

```powershell
powershell -ExecutionPolicy Bypass -File packaging\build_exe.ps1
```

脚本自动：建 `.build-venv` → 装 PyInstaller → 生成图标 → 打包 → 打便携 zip → 启动自检。

产物：

```
dist\知源学伴\知源学伴.exe          ← 双击运行（2.4 MB）
dist\知源学伴\_internal\...         ← 依赖与资源，不要单独删
dist\知源学伴-便携版.zip            ← 约 12 MB，发给同学解压即用
```

### 数据存哪

| 平台 | 位置 |
|---|---|
| Windows | `%APPDATA%\知源学伴\` |
| macOS | `~/Library/Application Support/知源学伴/` |
| Linux | `~/.local/share/知源学伴/` |

可用环境变量 `ZY_DATA_DIR` 覆盖（做便携版/U 盘运行时有用）。

目录内容与源码版一致：

```
%APPDATA%\知源学伴\
├── config.json      # AI 接入配置（首次自动生成）
├── vocab/ knowledge/ bank/ rubrics/   # 静态资源（首次从 exe 内复制出来）
└── db/              # 所有学习数据 + _metrics/ 指标
```

**卸载 exe 不会删数据**：删掉程序文件夹后，数据仍在 `%APPDATA%`，重装后自动接着用。

### 为什么选择「文件夹版」而不是单文件

| | 文件夹版（当前） | 单文件 |
|---|---|---|
| 启动速度 | 快（1 秒内） | 慢（每次解压 30+ MB，3–5 秒） |
| 杀毒误报 | 低 | 较高 |
| 体积 | 12 MB（zip） | 30 MB |
| 分发 | 一个 zip，解压后双击 | 一个 exe |

### 第一次用（给同学的说明）

1. 解压 `知源学伴-便携版.zip`
2. 双击 `知源学伴.exe`（Windows 可能提示"未识别的应用"，点 **更多信息 → 仍要运行**）
3. 浏览器会自动打开 `http://127.0.0.1:8765`
4. 想用 AI：侧栏「⚙ 接入设置」→ 智谱 GLM → 填自己的免费 Key

> exe 未做代码签名，所以首次运行 Windows SmartScreen 会拦一下，这是正常的。

### 桌面版 vs 服务器版的取舍

| | 桌面版 exe | 服务器/隧道版 |
|---|---|---|
| 安装 | 每人一份 | 一个地址大家用 |
| AI 额度 | 各用各的 Key | 各用各的 Key 或共享 |
| 数据 | 各在自己电脑，互不可见 | 集中，可看全班 |
| **管理端** | 只能看**自己这台机器**的数据 | 能看**全班** |
| 需要开机 | 只在自己用时 | 要一直开着 |

> 想要"看全班"就必须有人跑服务器 —— exe 天然做不到这点。

## 三、常见问题

| 现象 | 处理 |
|---|---|
| 双击 exe 报"Windows 保护了你的电脑" | 更多信息 → 仍要运行；或右键属性解除锁定 |
| 端口 8765 被占用 | 程序会自动往后找 8766/8767…，控制台会打印实际地址 |
| 管理端看不到数据 | 指标从本版本开始记录；老数据不会回溯统计 |
| 公网部署看不到「管理端」 | 没设 `ZY_ADMIN_TOKEN`，管理端被自动关闭（防止任何登录用户看全班数据） |
| 想清空演示数据 | 删掉 `%APPDATA%\知源学伴\db` 整个目录（会丢所有学习数据） |
| 打包报 `No module named PyInstaller` | 删掉 `.build-venv` 重新跑构建脚本 |
