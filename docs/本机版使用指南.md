# 本机版使用指南

> 只在自己电脑上用（不用买服务器、不用域名、零成本）。装好 Python 就能跑，所有数据都在你自己硬盘上。

---

## 一、准备（只需做一次）

### 1. 装 Python 3.8+

- 下载：<https://www.python.org/downloads/windows/>
- 安装时**务必勾选** `Add python.exe to PATH`
- 验证：按 `Win + R` → 输入 `cmd` → 回车 → 输入 `py -3 -V`，能打印版本号即可

> 本项目**纯标准库**，不需要 pip 安装任何依赖。

### 2. 拿到代码

```bat
git clone https://github.com/HZX-26378130/zhiyuan-study.git
cd zhiyuan-study
```

没有 git？在 GitHub 页面点 **Code → Download ZIP** 解压也行。

---

## 二、启动（每次用都做）

**方式 A（推荐）**：双击项目里的 `启动.bat`

**方式 B**：命令行

```bat
cd /d 项目路径\zhiyuan-study
py -3 server.py
```

然后浏览器打开 **<http://127.0.0.1:8765>**

启动成功时会打印：

```
  大模型: 已配置 ✓  (glm-4-flash)      ← 或「未配置 → 离线演示模式」
  词库:   CET-4 + CET-6（GitHub开源词库已内置）
  归档:   未启用（免费容器平台建议启用…）   ← 可选功能
  地址:   http://127.0.0.1:8765   （Ctrl+C 退出）
```

> 想换端口：`py -3 server.py 9000`
> 想让**同一 WiFi 下手机/平板**访问：先 `set ZY_HOST=0.0.0.0` 再启动，手机浏览器打开 `http://电脑局域网IP:8765`

## 三、第一次打开会看到什么

1. **新手引导**（8 步）自动播放，点「下一步」看完即可（之后可在侧栏「❓ 新手引导」重放）
2. 左上「学习档案」默认已有「我的档案」，可以点 `＋` 建多个（比如不同科目分开记）
3. 侧栏 13 个页面，建议顺序：

```
① 学习仪表盘   ← 总览：掌握度、薄弱点、今日复习
② AI 知识问答  ← 核心功能，粘贴题目就能问
③ 英语批改     ← 四六级作文/翻译
④ 四六级词汇   ← 每日刷词
⑤ 诊断卷       ← 按薄弱点自动出卷
⑥ 错题本       ← 做错的自动归到这儿，可变式重练
⑦ 其余（讲义 / 计划 / 知识图谱 / 校本资料 / 学习记忆）
```

## 四、AI 能力怎么配（三档，按需要选）

不配也能用（内置知识库 + 启发式批改 + 真题库），但配了才是完整版。

### 档位 1：什么都不配（离线模式）

- 能用：知识点匹配、规则批改、真题库、词汇测验、诊断卷（题库拼装）
- 不能用：真实的 AI 讲解、AI 批改、AI 命题

### 档位 2：免费 Key（**推荐**，2 分钟）

1. 打开 <https://open.bigmodel.cn> 注册（邮箱/手机号，免费）
2. 控制台 → API Keys → 新建，复制
3. 应用里点侧栏 **「⚙ 接入设置 / API」**
4. 「服务商预设」选 **智谱 GLM** → 粘贴 Key → **保存**
5. 点「测试连接」看到 `✓ 连接成功` 即可

> `glm-4-flash`（对话）和 `glm-4v-flash`（看图）都是**长期免费**的。
> 有视觉模型才能用「拍照读题」和「手写作文拍照批改」。

### 档位 3：完全离线免费（Ollama）

1. 装 <https://ollama.com>
2. 命令行 `ollama pull qwen2.5:7b`
3. 设置里选「本地 Ollama」→ 保存

> 好处：不联网、不花钱、隐私最好；代价：小模型讲题质量不如云端。

### 档位 4：不填 Key 也能试（免 Key 公益通道）

`config.json` 里默认带一条 Pollinations 兜底，没 Key 时会自动用它。
**限 1 次 / 45 秒、无读图能力**，只适合偶尔试一下。

## 五、数据在哪 / 怎么备份

| 内容 | 位置 |
|---|---|
| 所有学习数据（档案/错题/积分/讲义/图片） | `data/db/` |
| AI 接入配置（含 API Key） | `config.json` |

**备份**：点「⚙ 接入设置 → ⬇ 备份数据」下载 zip；
或直接复制整个 `data\db` 文件夹（换电脑时拷过去即可）。

> `data/db` 和 `config.json` 都不要传到 GitHub（`.gitignore` 已排除）。

## 六、更新到新版本

```bat
cd /d 项目路径\zhiyuan-study
git pull
```

然后重启 `启动.bat`。数据在 `data/db`，更新不会覆盖。

> 没有 git 就重新下 ZIP，但**别覆盖** `data` 和 `config.json` 这两个。

## 七、常见问题

| 现象 | 原因与处理 |
|---|---|
| `py` 不是内部或外部命令 | Python 没加到 PATH，重装勾选 `Add python.exe to PATH` |
| 端口被占用 | `py -3 server.py 9000` 换端口，或关掉占用 8765 的程序 |
| 黑窗口中文乱码 | 命令行执行 `chcp 65001` 再启动（`启动.bat` 已自带这步） |
| 打开是「离线演示模式」 | 没配 Key 或 Key 失效，按第四节配一次 |
| 拍照读题提示"未配置视觉模型" | 需要带视觉的通道（智谱 `glm-4v-flash` 免费） |
| AI 回答很慢 | 可能是免 Key 兜底通道（45 秒限流），换智谱免费 Key 就快 |
| 换电脑数据丢了 | 复制旧电脑 `data\db` 覆盖到新电脑同位置 |
| 想给同学用 | 见 `deploy/windows/`：`tunnel.bat`（临时地址）或 `tunnel-ngrok.bat`（固定免费地址） |

## 八、单机 vs 多用户

| 模式 | 启动方式 | 登录 | 适用 |
|---|---|---|---|
| 单机（默认） | `py -3 server.py` | 不用登录 | 自己一个人用 |
| 多用户 | `set ZY_AUTH=1` 再启动 | 需注册/登录，数据按账号隔离 | 给同学用（配合隧道/服务器） |

> 单机模式下所有数据在一个档案体系里，谁打开浏览器都能看到——**公网暴露时必须开 `ZY_AUTH=1`**。

## 九、可选：自动归档

如果你打算长期用、怕误删，可以开每日归档（自动打包 `data/db` 到 GitHub 私有仓库）：

```bat
set ZY_ARCHIVE_GITHUB_REPO=你的账号/zhiyuan-backups
set ZY_ARCHIVE_GITHUB_TOKEN=github_pat_xxx
set ZY_ARCHIVE_INTERVAL_HOURS=24
py -3 server.py
```

详见 [deploy/archive/README.md](../deploy/archive/README.md)。
